# QuickOTP for Omarchy

A small Omarchy bar widget for [QuickOTP](https://github.com/devmobasa/QuickOTP).

- Click the key icon to open the searchable code popup.
- Right-click it to open the vault editor.

The main QuickOTP `install.sh` installs the application and offers to install and enable this widget when it detects Omarchy. Rerun the installer to update both.

The widget expects the standard QuickOTP commands at `~/.local/bin/quickotp-popup` and `~/.local/bin/quickotp-editor`.
